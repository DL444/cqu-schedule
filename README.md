# CQU Schedule

## 服务已终止

2026 年 6 月 10 日起，教务系统执行新的双重认证策略，用户在登录时除学号与密码外，还必须提供动态短信/邮箱验证码登录。

因为新的登录流程涉及必要的人工操作，所以包括本服务在内的自动化流程将无法登录到教务网完成日历获取与更新操作。因此，我们现已无法继续运营该服务。

我们已彻底删除所有用户数据，并在原页面中公示停止服务的通知。日历订阅的链接将在服务终止后的一段期间内固定返回空日历，以便从各类日历客户端清除原有的日历内容。本代码仓库将作存档处理。

我们理解学校对于信息安全保护的关切，并赞成学校执行的双重验证策略。但同时我们也始终支持开放、多元的教务信息访问渠道，支持学生在教务信息访问方面的选择权。我们对学校长期以来未能提供 API 等正式的程控数据访问接口深感遗憾。虽然期望渺茫，但我们希望学校能在未来提供此类接口。这不仅是一个开放、有活力的教务生态的需要，也是在人工智能应用背景下教务创新的重要支撑。

本服务运行的五年中，为上千名重大学子带来看了简单、高效的课程信息获取途径。其前身 UCQU 也曾运行三年。过去八年，感谢有你，我们后会有期！

## 原有自述

[CQU Schedule](https://schedule.dl444.net) 可以获取重庆大学课程信息，并生成相应的 iCalendar 日历订阅或 ICS 日历文件。

只需登录帐户即可生成订阅，无需手动导出 Excel 或提取 Cookie 等。

日历订阅支持自动更新。
